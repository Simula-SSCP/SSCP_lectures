# How to use this book

This book is organized into **parts** that correspond to the lecture topics in the course schedule. Each part contains:

- **Lecture material** — the theoretical content, typically as narrative text with equations and figures
- **Exercises** — interactive, code-based exercises that you can run in your browser

## Running the code

Exercise notebooks can be launched interactively using the launch buttons (🚀) at the top of each page. During the summer school, notebooks are available on the dedicated course JupyterHub server. Outside the school, you can use Binder or run them locally.

To run locally, install [Pixi](https://pixi.sh/) and then:

```bash
pixi install
pixi run jupyter lab
```

## Solutions

Solutions to exercises are collected in the **Solutions** part at the end of the book. We encourage you to attempt the exercises before consulting the solutions.
