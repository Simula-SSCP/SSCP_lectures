# The bistable equation

To test our new finite difference method, we need an equation to solve. While we could plug the full Hodgkin-Huxley model into the reaction term $f(V)$ of our cable equation, tracking four different gating variables across thousands of spatial grid points can be mathematically overwhelming at first.

Instead, we will use the **bistable equation**. This is a well-known, heavily simplified mathematical model that produces the exact same travelling wave phenomenon using only a single variable.

## The reaction term

The reaction term for the bistable equation is defined as a simple cubic polynomial:

```{math}
:label: eq:bistable_reaction
f(V) = A V(1 - V)(V - \alpha)
```

where $\alpha$ is a parameter between 0 and 1, and $A$ is a scaling parameter that controls the speed of the reaction.

Plugging this into our scaled 1D cable equation gives us the complete bistable reaction-diffusion equation:

```{math}
:label: eq:bistable_full
\frac{\partial V}{\partial t} = k \frac{\partial^2 V}{\partial x^2} + A V(1 - V)(V - \alpha)
```

## Equilibrium points

To understand how this equation works, let us temporarily turn off the spatial diffusion ($k = 0$) and look only at the isolated reaction term: $\frac{\partial V}{\partial t} = A V(1 - V)(V - \alpha)$.

Because it is a cubic polynomial, the right-hand side has exactly three zeros: $V = 0$, $V = \alpha$, and $V = 1$. These are the **equilibrium points** of the equation (points where the voltage is no longer changing).

```{figure} ../../figs/cubic.png
Plot of the cubic reaction term $f(V)$ with $\alpha = 0.5$. Notice the three zero-crossings.
```

If we perturb the voltage slightly away from these points, we observe the following behaviour:

- **$V = 0$ is stable:** If the voltage rises slightly, $f(V)$ becomes negative, pulling the voltage back down to 0. (This represents the resting membrane potential.)
- **$V = \alpha$ is unstable:** This acts as a strict threshold. If the voltage crosses exactly above $\alpha$, $f(V)$ becomes strongly positive, rapidly driving the voltage higher.
- **$V = 1$ is stable:** The voltage will stabilize here once it is fully activated. (This represents the peak of an action potential.)

## The travelling front

If a single point in space is pushed above the threshold $\alpha$, it will rapidly shoot up to 1. Because of the spatial diffusion term ($k \frac{\partial^2 V}{\partial x^2}$), this highly energized point will "leak" voltage into its immediate physical neighbours.

Those neighbours will subsequently be pushed above the threshold $\alpha$, causing them to shoot up to 1, which leaks into _their_ neighbours, and so on. This domino effect perfectly describes active conduction, resulting in a **travelling front** of electrical activation that propagates smoothly down the cable.

## The boundary value problem

To simulate the bistable equation on a computer, we must define a complete initial-boundary value problem (IBVP). We solve on a spatial domain $\Omega = [0, L]$:

```{math}
:label: eq:bistable_ibvp
\begin{alignat*}{2}
v_t &= k v_{xx} + f(v) & \quad \text{for} \quad & t > 0,\; 0 < x < L, \\
v_x &= 0 & \quad \text{for} \quad & x = 0,\; x = L, \\
v &= v_0 & \quad \text{for} \quad & t = 0,\; 0 < x \leq L/10, \\
v &= 0 & \quad \text{for} \quad & t = 0,\; L/10 < x \leq L,
\end{alignat*}
```

where we use the compact notation $v_t = \frac{\partial v}{\partial t}$ and $v_{xx} = \frac{\partial^2 v}{\partial x^2}$. The boundary condition $v_x = 0$ at both ends is a Neumann (no-flux) condition, representing sealed cable ends — no current flows in or out.

The initial condition places a small perturbation ($v_0 > \alpha$) at the left end of the cable. Because $v_0$ exceeds the threshold $\alpha$, this region will fire and trigger a travelling front that propagates to the right.

Typical parameter values are:

| Parameter | Value |
|-----------|-------|
| $k$ (diffusion coefficient) | 2.0 |
| $A$ (reaction scaling) | 1.0 |
| $\alpha$ (threshold) | 0.1 |
| $L$ (cable length) | 100 |
| $v_0$ (initial perturbation) | 0.3 |

## Explicit update scheme for the bistable equation

Applying the general explicit finite difference scheme from the previous section to the bistable equation gives the following update formulas. For the **interior points** ($i = 1, 2, \ldots, N-1$):

```{math}
:label: eq:bistable_interior
v_i^{j+1} = v_i^j + \frac{k \Delta t}{\Delta x^2}\left(v_{i-1}^j - 2v_i^j + v_{i+1}^j\right) + \Delta t \, f(v_i^j)
```

This follows directly from the general formula derived in the finite difference section.

### Boundary treatment: the ghost point approach

At the boundaries ($i = 0$ and $i = N$), we cannot directly apply the interior formula because it would require values outside the domain ($v_{-1}$ or $v_{N+1}$). We must instead use the Neumann boundary condition $v_x = 0$ to determine these missing values.

The central difference approximation for the first derivative at $i = 0$ is:

```{math}
:label: eq:ghost_point_derivation
\frac{\partial v}{\partial x}\bigg|_{x_0} \approx \frac{v_1 - v_{-1}}{2\Delta x} = 0 \quad \Longrightarrow \quad v_{-1} = v_1
```

The fictitious point $v_{-1}$ is called a **ghost point**. Substituting $v_{-1} = v_1$ into the standard central difference formula for the second derivative gives:

```{math}
\frac{v_1 - 2v_0 + v_{-1}}{\Delta x^2} = \frac{2(v_1 - v_0)}{\Delta x^2}
```

This yields the update formula for the **left boundary** ($i = 0$):

```{math}
:label: eq:bistable_left_bc
v_0^{j+1} = v_0^j + \frac{k \Delta t}{\Delta x^2} \cdot 2\left(v_1^j - v_0^j\right) + \Delta t \, f(v_0^j)
```

By the same reasoning (using $v_{N+1} = v_{N-1}$), the **right boundary** ($i = N$) update is:

```{math}
:label: eq:bistable_right_bc
v_N^{j+1} = v_N^j + \frac{k \Delta t}{\Delta x^2} \cdot 2\left(v_{N-1}^j - v_N^j\right) + \Delta t \, f(v_N^j)
```

:::{admonition} Note the factor of 2
:class: warning

The factor of 2 in the boundary formulas is not a typo — it arises naturally from the ghost point substitution. Forgetting this factor is a common source of errors when implementing Neumann boundary conditions.
:::
