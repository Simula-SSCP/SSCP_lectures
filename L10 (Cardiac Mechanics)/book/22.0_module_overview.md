# Module overview

```{note}
The theoretical material for this module is currently only available as slide presentations.
```

While previous modules focused heavily on electrical excitation and intracellular calcium handling, this module shifts focus to the physical, macroscopic properties of the heart.

We will zoom out to look at the mechanical function of the whole organ, the 3D physics of tissue deformation, and the systems-level biochemical networks that tie everything together. Because this material spans a massive range of biological, clinical, and mathematical disciplines, the core theory is provided via presentation slides.

:::{admonition} What you will learn
:class: tip

1. **Ventricular function:** Hemodynamics, stroke work, the cardiac cycle, and Pressure-Volume (PV) loops.
2. **Cardiac muscle:** The physiological basis of the Frank-Starling mechanism and length-dependent activation.
3. **Nonlinear biomechanics:** Using continuum mechanics, finite strain tensors, and Cauchy stress to model hyperelastic tissue.
4. **Statistical shape atlases:** Applying data science and Principal Component Analysis (PCA) to extract 3D shape variations from medical imaging.
5. **Network modelling:** Using Boolean logic and software tools like Netflux to model complex biochemical signaling cascades.
   :::

At the end of the module, you will find an interactive coding exercise that allows you to directly manipulate and explore a Statistical Shape Atlas using Python.
