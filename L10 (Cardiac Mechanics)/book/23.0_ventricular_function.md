# Ventricular function

```{note}
The theoretical material for this chapter is currently only available as a slide presentation.
```

This lecture covers the macroscopic pump function of the heart. Key topics include the cardiac cycle (the Wiggers Diagram), the creation and interpretation of Pressure-Volume (PV) loops, and the concepts of preload, afterload, and cardiac contractility.
