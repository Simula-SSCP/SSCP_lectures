# Network modelling

```{note}
The theoretical material for this chapter is currently only available as a slide presentation.
```

This final lecture shifts away from traditional physics and enters the realm of systems biology. It explores how cells process information via incredibly complex biochemical reaction networks and intracellular signaling cascades. You will learn about logical network representations (Boolean networks using AND/OR gates) and how researchers use software tools like Netflux to model these networks.
