# Statistical shape atlases

```{note}
The theoretical material for this chapter is currently only available as a slide presentation.
```

This lecture bridges clinical imaging and data science. It details how the Cardiac Atlas Project uses cardiovascular magnetic resonance (CMR) imaging and deep learning to build large-scale statistical shape atlases. You will also learn how Principal Component Analysis (PCA) is used to extract the primary modes of 3D shape variation across patient populations.
