# Module overview

Up to this point in the course, we have treated the cell as a single, uniform point in space. We assumed that when an action potential fired, the entire cell membrane depolarized perfectly simultaneously. For small, compact cells, this is a reasonable simplification.

However, biological cells—especially neurons and muscle fibers—can be incredibly long, extended structures. If an action potential fires at one end of a meter-long motor neuron, how does that electrical signal physically travel down the axon to the other end without dying out?

In this module, we transition from zero-dimensional point models to one-dimensional spatial models to understand how electricity physically moves through biological tissue.

:::{admonition} What you will learn
:class: tip

1. **Transmission line history:** How the 19th-century mathematics used to lay submarine telegraph cables perfectly describes the biological axon.
2. **The cable equation:** Deriving the partial differential equation (PDE) that dictates how voltage changes over both time and physical space.
3. **Finite Difference Methods (FDM):** How to discretize continuous space and time to solve complex PDEs using Python.
4. **The FitzHugh-Nagumo model:** Simulating propagating action potentials and modeling the dangerous "reentry" circuits responsible for cardiac arrhythmias.
:::

By the end of this module, you will have written a spatial solver from scratch, allowing you to watch a simulated wave of electricity propagate smoothly down a biological cable.
