# Simulating the action potential

We now have all the individual puzzle pieces required to build a computational model of an excitable cell.

In Module 2, we learned that the cell membrane acts as a capacitor, and that the flow of ions across the membrane generates currents that change the membrane potential. In the previous chapters of this module, we learned exactly how to write mathematical equations for the voltage-sensitive gating of those ion channels.

In this chapter, we will finally put these pieces together. We will assemble the full Hodgkin-Huxley equivalent circuit—combining sodium, potassium, and leak currents—and integrate the resulting system of differential equations. By the end of this chapter, you will have written the code to fire your very first simulated action potential!
