# A brief introduction to Python for scientific computations

This is a short introduction to the Python programming language and the Jupyter notebook format. This is a school on computational physiology, and you will be using programming throughout the course to implement and solve various mathematical models, analyze results, and produce plots.

Today we aim to give you a quick introduction and overview of Python and its syntax. If you are already familiar with Python, this can act as a quick refresher. As the school progresses, you will have ample opportunity to use Python to solve various exercises and get more experience and practice. If you are completely new to Python, don't panic! We will have teaching assistants present to help you along.

You can use this material to cover any of the topics in more detail than we have time for in the live session. Alternatively, you can use it as a reference later to refresh your memory on specific syntax.

:::{admonition} What we will cover
:class: tip

- An introduction to Jupyter
- Variables and types
- Tests and conditionals
- Loops
- Plotting
- Defining functions
- Solving differential equations numerically
  :::

If you want a more thorough introduction to scientific programming with Python, there are plenty of good books and courses out there, many of them open access. We highly recommend the following open-access book by Joakim Sundnes:

- [Introduction to Scientific Programming with Python](https://doi.org/10.1007/978-3-030-50356-7)

If there are any specific topics you want to learn more about, please do not hesitate to let us know. We can try to cover these in more detail later in the course or find you an appropriate source on the topic.

_(Parts of this material are based on an introduction to Python written by Hans Petter Langtangen and Leif Rune Hellevik, which you can find on [GitHub](https://github.com/hplgit/bumpy).)_
