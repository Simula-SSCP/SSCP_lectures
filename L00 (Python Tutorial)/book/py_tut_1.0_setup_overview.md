# Setup and Jupyter basics

Before we can start writing and executing Python code, we need to understand the environment we are working in.

For the lecture part of this school, you will mostly be coding and computing in the cloud through a platform called JupyterHub. This means you won't have to install anything locally on your machine to participate in the daily exercises. However, if you want to work on projects locally, you will eventually need your own Python installation.

In this chapter, we will briefly cover how to set up Python on your own computer and choose a text editor. Then, we will dive into the basics of Jupyter Notebooks—the primary format we will be using throughout this course.
