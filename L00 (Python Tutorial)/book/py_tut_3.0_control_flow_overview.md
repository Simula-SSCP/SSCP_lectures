# Control flow and data structures

Up to this point, our Python programs have been entirely linear. The code has simply executed from top to bottom, one line at a time.

However, to build truly powerful scientific models, our code needs to be able to make decisions and repeat tasks. What if we want to run a calculation only _if_ a certain condition is met? What if we need to repeat a calculation thousands of times to simulate a process over time?

In this chapter, we will introduce **control flow**:

- **If-tests** to allow our code to make logical decisions.
- **While loops** and **For loops** to repeat tasks efficiently without writing the same code over and over.

We will also introduce **lists**, our first robust data structure, which will allow us to store, organize, and manipulate large sequences of data generated by our loops.
