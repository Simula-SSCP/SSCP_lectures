# Python fundamentals

Now that you have your environment set up and know how to execute cells in a Jupyter Notebook, it is time to write some actual Python code.

In this chapter, we will start from absolute scratch. We will write our very first line of code, learn how to use Python as a powerful scientific calculator, and understand how Python stores different kinds of information using variables and data types. Finally, we will look at how to neatly format our results so they are easy to read and interpret.

If you are already somewhat familiar with Python, much of this will be a review, but it is always good to double-check that you are comfortable with how Python handles variable assignment, mathematical imports, and string formatting before we move on to more complex logic.
