# Additional practice exercises

These exercises are meant to further familiarize you with Python and give you an opportunity to practice the coding concepts you have been shown in this tutorial.

Note that these exercises might be challenging for beginners, so please do not hesitate to collaborate on them with your peers or ask the teaching assistants for advice or help if you get stuck!

On the other hand, if you are more experienced and these exercises feel a bit too simple, we highly recommend going to [Project Euler](https://projecteuler.net) and trying to solve the first few mathematical challenges there using Python.

Good luck!
